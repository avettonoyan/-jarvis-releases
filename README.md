# Jarvis — releases

Installers for Jarvis, a voice assistant for your computer.

**Download:** open [Releases](../../releases/latest) and pick the file for your computer:

| Computer | File |
|---|---|
| Mac (Apple silicon, macOS 14.4+) | `Jarvis-<version>.dmg` |
| Windows | `Jarvis-<version>-setup.exe` |
| Linux | `Jarvis-<version>-x86_64.AppImage` |

Installed copies find new versions here by themselves and offer to update.
